
#### Software Development Life Cycle 
Это описание процесса разработки приложения от идеи до поддержания готового проекта.

В него входит: планирование, дизайн, разработка, отладка, деплой, поддержка

Он позволяет четко определить план разработки, ее этапы, определить ресурсы которые будут затрачены на это.
Помимо этого это обеспечивает стабильность, прозрачность и дальновидность проекта.
Помогает найти недочеты раньше времени и сопоставить это с ожиданиями пользователей.

#### Planning & feasibility analysis

На этом этапе планируются сроки, определяются примерные затраты и определяется сможет ли компания позволить себе этот проект.

![[Pasted image 20260813185632.png]]

#### Requirenmets specification (SRS)

Тут определяются функциональние и не-функиональные требования (т.е что приложение должно уметь еделать и сколько ресурсов жрать), которые потом сопоставляются с заказчиками.

![[Pasted image 20260813185854.png]]

#### System Design

Здесь проектируется набросок того как будет выглядеть архитектура приложения т.е какие модели использовать, какие технологии и т.д
Различают два последовательных уровня:
- High-level design - определяется архитектура приложения, структура базы данных, список технологий и главные модули
- Low-level design - тут выбираются API, структуры данных

![[Pasted image 20260813190218.png]]

#### Development (Coding)

Программисты пишут код и реализуют функционал, тестируют, дебажат и т.д

![[Pasted image 20260813190524.png]]

#### Testing

Смотрят с удовлетворениями требований и довольством пользователей.

Есть несколько этапов:
- Unit тестирование отдельных компонент
- Integration testing тестрирвание компонент в связке
- System Testing тестирование всего приложения
- Users Acceptance Testing (UAT) проверка удавлетворения пользователей
