


#### Protocol Data Unit
В OSI Информация между слоями передается блоками. эти блоки называются PDU
Каждый слой вносит (или удаляет) в мета-данные PDU какую-то свою информацию.

Например DataLink содержит в своем PDU ( называемый Fragment ) MAC-адресс, IP/TCP информацию отправителя и получятеля, порт

Network уже не знает мак адресса и содержит в себе TCP/IP аресса

Transport знает только конкретные порты.

процесс обертки информации одним слоем информации другого называется **Инкапсуляцией**
