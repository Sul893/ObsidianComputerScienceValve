

Веб сервер - это простая программа, которая коммуницирует с клиентами через интернет. С клиента приходит запрос на который сервер формирует ответ. При обмене используется [[HTTP]] т.к сервер отправляет статичный ресурс (HTML, CSS).
Лучше всего подходит ля статики, но может обладать и динамикой при желании

Поддерживается мультипоточность
