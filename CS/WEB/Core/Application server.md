

Это сервер, на котором запускаются приложения, который использует различные [[Communication protocol]] для разговора клиент-сервер.

Обладает динамикой и помимо управления web container еще умеет работать и с Java Been Container, что позволяет писать гораздо большие приложения

не поддерживается мультипоточность

грубо говоря обладает всем функционалом бэк энд сервера (запросы в БД, бины, шаблонизаторы и т.п)
