# Socket

**Сетевой сокет** — программная абстракция внутри сетевого узла компьютерной сети, служащая конечной точкой для отправки и получения данных по сети. По сути — "точка" в сети, через которую приложения обмениваются данными.

Сокет похож на трансивер: он одновременно и передаёт, и принимает данные.

## Аспекты понятия

В зависимости от контекста термин "сокет" употребляется в трёх смыслах:

- [[Socket address]] — идентификация сокета в сети: тройка Protocol + IP + Port.
- [[Socket API]] — программный интерфейс (уровень 7 модели OSI), через который приложение работает с сокетом. ^socketAPI
- [[Socket kernel]] — объект ядра ОС, выполняющий низкоуровневую работу с TCP. ^socketKernel

## Как это работает (на примере TCP)

```
Приложение А                                   Приложение Б
     │                                              │
     │ socket() → bind() → listen() → accept()       │
     │                ↓                       socket() → connect()
     │           [Socket Kernel]              [Socket Kernel]
     │                │          TCP-сегмент        │
     │                └───────── сеть ─────────────┘
     │  send()/recv()                          recv()/send()
     │                                            │
     └─────────────── close() ───────────────────┘
```

1. Сервер через [[Socket API]] создаёт сокет `socket()`, привязывает его к адресу `bind()`, переводит в режим ожидания `listen()`.
2. Клиент через `connect()` устанавливает соединение.
3. Сервер принимает `accept()` — получает **новый** сокет для конкретного клиента.
4. Обе стороны через `send()`/`recv()` обмениваются данными; данные проходят через [[Socket kernel]] в ядре ОС.
5. По окончании — `close()`.

## Использование

Сокеты лежат в основе любого сетевого взаимодействия. Веб-серверы, такие как [[Apache Tomcat]], используют сокеты для приёма HTTP-запросов от клиентов и отправки ответов.

В Java низкоуровневая работа с сокетами доступна через `java.net.Socket` / `java.net.ServerSocket` (обёртка над [[Socket API]]):

```java
try (ServerSocket server = new ServerSocket(8080)) {
    Socket client = server.accept();          // ждём соединения
    InputStream in  = client.getInputStream();
    OutputStream out = client.getOutputStream();
    // читаем HTTP-запрос, пишем HTTP-ответ
    out.write("HTTP/1.1 200 OK\r\n\r\nHello".getBytes());
    client.close();
}
```
