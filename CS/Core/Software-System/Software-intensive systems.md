Их главная цель - Манипуляции большими объемами данных для приобретения знаний и поддержки решений

На вход получают объекты, информацию

На выходе выдают объекты, информацию.

Оборудование: N-уровневая архитектура.

Примеры: сайты, СУБД, управление каталогом и т.д
