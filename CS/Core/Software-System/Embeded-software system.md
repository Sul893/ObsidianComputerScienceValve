
Системы встренного програмного обеспочения или системы реального времени. 

Их цель - автоматизация и оптимизация подсистем для получения максимально быстрого отклика

На вход обычно принимают информацию, полученную например с датчиков

Выполняются в реальном времени.

На выходе производят действия, продукция и т.д

Оборудование - микро/макро-процессорах

Пример: управление воздушным движением, системы вооружений, аэронавигация и управление летательным аппаратом

Обычно управляются операторами
